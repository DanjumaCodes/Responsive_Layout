About Cohort 9

Learning to build for every screen

We are learning how utility-first CSS and responsive thinking can turn simple ideas into websites that work everywhere.

A practical way to learn

Cohort 9 is exploring the building blocks of modern, responsive web pages. We practice by using Tailwind CSS classes to shape layouts, tune spacing, and make content adapt to different screen sizes.

Each small exercise helps connect a utility class to a visible result, from a flexible navigation bar to a grid that changes as the viewport grows.

What guides our work

  • 01Start with clear, useful content.
  • 02Build from mobile layouts upward.
  • 03Use responsive breakpoints with purpose.

Our learning path

Utility classes

Style directly in markup with small, composable classes.

Responsive layouts

Use breakpoints to adapt columns, spacing, and type.

Mobile-first design

Make the essential experience work on small screens first.
